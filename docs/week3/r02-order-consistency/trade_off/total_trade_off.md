## 구현 계획·검증으로 이어갈 것

추가 필수 트레이드오프 문답은 없다. 주문·포인트·상품의 구체적인 잠금 획득 순서, 충전·관리자 재고 설정 등 관련 변경 경로,
JPA 조회·매핑과 실제 SQL, 예외 전파·전체 롤백을 구현 계획에서 구체화한다.

업무 결과와 필수 경쟁 사례는 요구사항을 따른다. 실패 주입·worker·connection 등 테스트 구성은 구현 계획에서 정리한다.

## 보류한 비교

격리 수준은 이번 PR의 필수 트레이드오프에서 제외한다. 기존 설정을 유지하고 별도의 격리 수준 변경·비교 실험·설정 조사 과제를 추가하지 않는다.
비관적 잠금 조회부터 도메인 판단·저장까지의 보호와 필수 경쟁 사례 검증에 집중한다.
격리 수준과 관련된 구체적인 정합성·잠금 문제가 확인될 때 재검토한다. 특정 격리 수준의 우월성이나 실제 DB 설정 확인 완료를 의미하지 않는다.
5번은 이 보류 기록으로 관리하며 별도 상세 비교 파일은 만들지 않는다. 자동 재시도도 실제 필요가 확인될 때 재검토한다.
