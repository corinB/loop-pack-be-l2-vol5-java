## 유지하는 전제

논리 삭제, 브랜드·상품의 단일 트랜잭션, 재고 0인 상품 포함, 이미 삭제된 상품의 상태 유지,
다른 대상·과거 주문 보존은 요구사항이다. 실제 SQL 실행 뒤 전체 롤백을 검증한다.
브랜드 삭제와 상품 등록의 동시 실행은 이번 범위에서 제외한다.
