이미 정한 재고 선차감, 확정 실패 시 한 번 복구, 미확인 시 유지, 관찰 먼저 commit, 파사드/TX 컴포넌트 분리, 복구 작업 CAS는 다시 미정으로 돌리지 않는다.
고객 confirm은 PG 결제이며 포인트를 사용하지 않는다. 같은 주문·키·조건은 기존 시도를 재사용한다. 실제 PG 생성은 PENDING 응답이므로 최종 성공·실패는 연결한 수동 대사로 재확인할 수 있다. callback도 연결했고 알림 본문 대신 PG 권위 조회로 확인한다. 생성 전 확정 거절은 즉시 실패 처리·재고 복구한다. 자동 재조회·회로·fallback은 PR03이다.

- 기능 구현만 커밋 전에 비즈니스·사용자 경험·기술 서브에이전트 리뷰를 받는다.
