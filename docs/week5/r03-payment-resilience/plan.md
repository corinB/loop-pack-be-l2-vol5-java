## 이번 문답에서 확정한 것

- 첫 자동 조회는 작업 시작 후 즉시, 추가 3회는 1·3·10초와 지터 ±20%다.
- 명확한 실행기 접수 거절은 100ms 뒤 전달만 한 번 재시도하고 재거절은 수동 전환한다. 불명확한 접수 오류는 재전달하지 않는다.
- 자동/수동/callback의 PG 조회는 회로 하나를 공유한다. 차단 시 자동은 확보 회차 유지·즉시 수동, HTTP 0회·회로 표본 제외다. 저장 종결 재적용은 회로 밖이다.
- 정상·실패·제외, 4xx 경로 구분과 회로 실패/결제 실패/재조회 차이는 [집계 문서](trade_off/02-lookup-circuit-breaker.md)를 따른다.
- 다음은 회로 집계 창·최소 표본·차단/느림 수치다. 전체 시간 예산·내부 반영 재시도·자동 시작 대상/선점·실행기·라이브러리 연결과 최소 검증을 정한 뒤 상세 계획·세 관점 계획 리뷰를 진행한다.
