[대표 문서](order-discount-contract.md) · [설계할 API 계약](api-contract.md)

**상태: 이번 범위 제외·추후 진행.** 테스트 코드 작성·기존 테스트 실행·실제 HTTP 요청과 관찰은 이번 설계 문서 작업에서 수행하지 않는다. 아래 양식은 보존하며 실제 결과나 통과 여부를 채우지 않는다. `관찰 예정`은 미실행 상태를 뜻한다.

## 추후 관찰 재개 시 점검 — 이번 완료 기준에서 제외

- [ ] 기존 테스트를 읽고 실행했다.
- [ ] ContractClassificationTest에서 네 입력을 실제로 요청했다.
- [ ] 각 입력의 HTTP status·meta.result·error code·data 유무를 검증했다.
- [ ] 관찰 결과를 위의 한 표에 모았다. 별도 curl 로그는 제출하지 않는다.
- [ ] 세 테스트 대상의 통과와 실제 실행 수·skip 여부를 확인했다.
- [ ] 허용 범위 밖의 변경이 없음을 확인했다.
